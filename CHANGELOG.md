# Changelog

All notable changes to this project are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [0.4.0] - Unreleased

### Added

- Fourier-series and Fourier-transform foundations using complex exponentials.
- Quantum-phase module distinguishing global phase from relative phase.
- Primary MIT OpenCourseWare references for Fourier and quantum-phase material.

### Boundaries

- Version `0.4.0` remains unreleased pending independent signal-processing and quantum review.
- The quantum module does not claim that Euler's identity by itself is quantum interference or that quantum mechanics proves spiritual interpretations.

## [0.3.0] - Unreleased

### Added

- Waves-and-phasors module using $Ae^{i(\omega t+\phi)}$.
- Relative-phase and equal-amplitude cancellation explanations.
- Accessible relative-phase laboratory and JavaScript phasor tests.

### Boundaries

- Version `0.3.0` remains unreleased pending independent engineering or signal-processing review.

## [0.2.0] - Unreleased

### Added

- Differential-equation derivation of unit-circle motion from $f'(\theta)=if(\theta)$.
- Matrix-exponential derivation of planar rotation from $J^2=-I$.
- Accessible matrix-rotation laboratory with configurable vectors and angles.
- JavaScript tests for rotation, determinant preservation, accessibility metadata, and evidence boundaries.

### Fixed

- Restored inline mathematical formatting in the new differential-equation and matrix documentation.

### Boundaries

- Version `0.2.0` remains unreleased until independent mathematical review is complete.
- Later phasor, Fourier, and quantum teaching modules are implemented on the separate unreleased `0.3.0` and `0.4.0` development paths and remain subject to their own review gates.

## [0.1.1] - Unreleased

### Changed

- Corrected exact-versus-approximate special-angle labeling.
- Added reduced-motion quarter-turn stepping and explicit inactive-tab pause status.
- Added a dedicated quiet live-status region, fail-closed controls, and a no-JavaScript fallback.
- Preserved exact special-angle presets while making keyboard range movement deterministic.
- Added hosted Chromium/Firefox/WebKit UAT plus a required Chromium smoke inside CI.
- Added canonical post-deploy production smoke for the public site and development laboratories.
- Expanded the current-main Python compatibility matrix and refreshed development/test tooling.
- Updated public metadata to the verified canonical `https://eulers.id/` domain.
- Added same-origin CSP and no-referrer browser metadata.
- Expanded finite-series tests across representative moderate complex inputs.
- Clarified current-release versus future-module claims in the claims register.
- Corrected stale citation-control wording.

### Boundaries

- No new advanced differential-equation, Fourier, phasor, or quantum learning modules.
- Human learner observation, manual screen-reader review, and physical-device review remain `0.1.x` validation activities.

## [0.1.0] - 2026-07-29

### Added

- A concise public README centered on Euler's identity and the interactive journey
- A standard Python package under `src/eulers_identity`
- Direct numerical verification of Euler's identity
- Exponential power-series approximation
- Unit-circle and rotation-matrix helpers
- Explicit complex-number tolerance handling
- Automated Python and JavaScript tests
- Linux and Windows continuous-integration checks
- A responsive SVG unit-circle experience for GitHub Pages
- Keyboard, focus, reduced-motion, and live-region accessibility controls
- Mathematical, numerical, interpretive, and reference documentation
- A classified claims register
- Contribution, conduct, security, citation, and dual-license files
- Public-neutrality guardrails for documentation and metadata

### Verified

- The standard derivation and power-series derivation
- Cardinal unit-circle values and magnitude preservation
- The three-step explanation from $1$ to $-1$ to $0$
- Numerical residual handling near machine precision
- JavaScript geometry and Play/Pause accessibility behavior
- Internal links, package installation, examples, and static-site assets

### Boundaries

- No backend, accounts, advertising, analytics, or data collection
- Advanced differential-equation, Fourier, phasor, and quantum modules remain on the roadmap
- Learner observation and broader manual assistive-technology validation remain `0.1.x` activities
- The project does not claim that Euler's identity proves God, proves a consciousness field, or independently establishes a theory of gravity
