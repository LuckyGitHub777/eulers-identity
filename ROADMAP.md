# Roadmap

The repository grows through completed, reviewable learning gates.

## Version 0.1.0 — Foundation

- [x] Direct derivation
- [x] Complex-plane explanation
- [x] Power-series derivation
- [x] Numerical verification and tolerance explanation
- [x] Tested Python package
- [x] Accessible interactive unit circle
- [x] Claims register and interpretation boundary

## Version 0.1.x — Validation and refinement

- [ ] Observe at least one learner unfamiliar with complex numbers
- [ ] Observe at least one learner comfortable with algebra and trigonometry
- [ ] Obtain feedback from at least one technically trained reviewer
- [ ] Complete manual screen-reader review
- [ ] Complete physical mobile-device review
- [ ] Incorporate evidence-based accessibility and learning refinements

These activities strengthen the foundation after the technical `0.1.0` release.
They become mandatory completion gates for `1.0.0`.

## Version 0.2.0 — Differential equations and matrices

- [x] Derive $f'(\theta)=if(\theta)$ with $f(0)=1$
- [x] Explain perpendicular velocity and circular motion
- [x] Derive the matrix exponential
- [x] Add a matrix-rotation laboratory
- [ ] Obtain an independent mathematical review

The written derivations and interactive matrix laboratory are implemented for
review. Version `0.2.0` remains unreleased until an independent mathematical
review is complete.

## Version 0.3.0 — Waves and phasors

- [ ] Introduce $Ae^{i(\omega t+\phi)}$
- [ ] Connect rotation to sine and cosine traces
- [ ] Demonstrate relative phase
- [ ] Demonstrate equal-amplitude cancellation
- [ ] Add engineering examples without overclaiming

## Version 0.4.0 — Fourier and quantum phase

- [ ] Introduce Fourier building blocks
- [ ] Distinguish Fourier series and Fourier transforms
- [ ] Explain global and relative quantum phase
- [ ] Connect relative phase to interference
- [ ] Add primary references and technical review

## Version 1.0.0 — Complete mastery experience

- [ ] Complete every documented mastery gate
- [ ] Complete desktop and mobile accessibility review
- [ ] Validate with beginner, intermediate, and technical learners
- [ ] Complete independent mathematical review
- [ ] Stabilize all interactive laboratories
- [ ] Publish complete references and release evidence

## Explicitly deferred

The project does not currently plan user accounts, a backend, analytics,
remote APIs, an AI tutor, or automated metaphysical interpretation.
